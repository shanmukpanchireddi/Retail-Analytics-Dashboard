# Retail Analytics Dashboard

## Project Overview

This project is a Retail Analytics Dashboard built using:

- Python
- Power BI
- Streamlit
- Machine Learning

The project provides insights into:

- Executive Dashboard
- Sales Analysis
- Customer Segmentation
- Demand Forecasting
- Inventory Optimization

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Power BI
- Streamlit

## Files

- app.py
- RetailPulses project1.pbix
- cleaned_retail_data (1).csv.xlsx
- customer_rfm.csv
- forecast_results.csv
- inventory_optimization.csv
